## Technical distinction

SHA-256 fingerprints are calculated from file bytes. HASHME records the
relationship locally but does not write a hash into or otherwise modify a
dropped source file. A result can be independently reproduced with any correct
SHA-256 implementation.

## Baseline declaration

Version 1.0 is the first HASHME baseline. Compatible corrections after this
baseline use the v1.1, v1.2, v1.3 sequence unless KANE-O authorises a new product
class or breaking major release.

Version 1.1 implements KANE-O's first Windows device-test refinements while
preserving the v1.0 product identity, local data location, and upgrade line.

Version 1.2 completes the compact production presentation: the supplied HashMe
mascot is embedded into the executable, the floating strip is one-third narrower,
and the installer provides visible progress and an explicit completion page.
It preserves the v1.0 product identity, local catalogue, settings, and approved
upgrade line.
