# Contributing to HASHME

HASHME is publicly available as source under the PolyForm Noncommercial License
1.0.0. Public issues are welcome for reproducible defects, documentation
corrections, and narrowly scoped proposals.

Code contributions and pull requests are not currently accepted. Contributor IP
terms must be published before external code can be merged.

When reporting a defect:

1. State the HASHME version and Windows version.
2. Use non-sensitive reproduction files.
3. Include the observed and expected behaviour.
4. Never include signing keys, PFX files, certificate passwords, personal file
   paths, local catalogues, or confidential source files.

Security vulnerabilities must not be reported in a public issue. Follow
[SECURITY.md](SECURITY.md).

The governing product standard is simple: reliability and visual identity are
both release requirements. A generic-looking working build and a beautiful
unreliable build are equally incomplete.
